# Privacidad y ética del banco de pruebas

Solo se utilizan alertas y alias sintéticos. El repositorio no guarda biometría, audio personal, nombres reales ni ubicaciones sensibles.

El código HTTP del banco de pruebas no está diseñado para producción ni para alertas a instituciones públicas. El futuro cifrado requiere implementación, gestión de claves y pruebas independientes.
